# 🏍️ Ducati Clone

A modern and responsive Ducati-inspired motorcycle website built using **HTML, CSS, and JavaScript**.

## ✨ Features

- Responsive design
- Ducati motorcycle showcase
- Technical specifications table
- Modern UI/UX
- Smooth animations
- Test Ride form
- Mobile navigation
- Form validation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Vercel

🚀 Deployment

This website is deployed using Vercel.

Deployment Steps
Upload the project to GitHub.
Go to Vercel.
Import the GitHub repository.
Select the project.
Click Deploy.
Vercel automatically hosts the website.
